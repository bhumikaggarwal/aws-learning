# What is Cloud Computing?

## Definition

Cloud computing is the on-demand delivery of computing services over the internet. Instead of buying, owning, and maintaining physical infrastructure, organizations rent computing resources from a cloud provider whenever they need them.

In simple words,
> Instead of buying and managing your own computers and servers, you rent computing resources from a cloud provider whenever you need them.

---

# The Core Idea Behind Cloud Computing

The fundamental idea behind cloud computing is:

> **Use computing resources as a service instead of owning the infrastructure.**

Rather than purchasing expensive hardware and maintaining it yourself, you consume computing resources only when required and pay only for what you use.

This helps organizations:

- Reduce infrastructure costs
- Avoid large upfront investments
- Deploy applications faster
- Scale resources according to demand

---

# Real-Life Example

## Traditional Way

Suppose you want to watch a movie.

Earlier you had to:

- Buy a DVD
- Buy a DVD player
- Store the DVDs
- Maintain the DVD player

You owned the complete infrastructure.

## Cloud Way

Today you simply open:

- Netflix
- Amazon Prime Video
- Disney+ Hotstar
- JioHotstar
- Sony LIV

You don't own:

- Servers
- Storage
- Networking infrastructure

You simply consume the service.

This is exactly how cloud computing works.

---

# Business Example

Suppose you start a new company.

## Without Cloud (Traditional IT)

You would need to:

- Buy physical servers
- Buy storage devices (HDDs/SSDs)
- Purchase networking equipment
- Rent space for a server room
- Install operating systems
- Configure networking
- Hire IT staff
- Maintain hardware
- Replace failed components
- Plan for future growth

This requires a huge upfront investment and continuous maintenance.

---

## With Cloud

Instead of purchasing hardware, you simply rent resources.

You can:

- Create a virtual server within minutes
- Pay only for what you use
- Increase resources whenever traffic increases
- Decrease resources when demand is low
- Let the cloud provider maintain the physical hardware

This allows businesses to focus on building products rather than managing infrastructure.

# Key Points to Remember

- Cloud computing means renting IT resources instead of owning them.
- Resources are available over the internet.
- You pay only for what you consume.
- Cloud providers manage the underlying physical infrastructure.
- Businesses can focus on applications instead of hardware.

# Interview Definition

Cloud computing is the on-demand delivery of computing services such as servers, storage, networking, databases and software over the internet with pay-as-you-go pricing. It enables organizations to scale resources quickly without investing in or maintaining physical infrastructure.
