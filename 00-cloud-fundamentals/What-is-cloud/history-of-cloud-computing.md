┌──────────────────────────────────────────────────────────────┐
│ 1. 1950s – MAINFRAME ERA                                    │
└──────────────────────────────────────────────────────────────┘

• Huge computers occupied entire rooms.
• Extremely expensive.
• Used only by governments, banks, universities, and the military.
• One computer served very few users.

Problem
• High infrastructure cost.
• Most computing power remained unused.

Key Takeaway
Need a way to share computing resources.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 2. 1960s – TIME SHARING                                     │
└──────────────────────────────────────────────────────────────┘

Innovation
• Multiple users shared one mainframe.
• CPU switched rapidly between users.

Benefits
• Better resource utilization.
• Lower computing cost.
• First major step toward cloud computing.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 3. 1961 – JOHN McCARTHY'S VISION                            │
└──────────────────────────────────────────────────────────────┘

Quote
"Computation may someday be organized as a public utility."

Meaning
• Computing should work like electricity.
• Use resources whenever needed.
• Pay only for what you consume.

Importance
Conceptual foundation of cloud computing.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 4. 1970s – VIRTUALIZATION                                   │
└──────────────────────────────────────────────────────────────┘

Innovation
• One physical server could run multiple Virtual Machines (VMs).
• Each VM behaved like an independent computer.

Benefits
• Better hardware utilization.
• Reduced infrastructure cost.
• Efficient resource sharing.

Importance
Virtualization is the backbone of modern cloud computing.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 5. 1980s – PERSONAL COMPUTER REVOLUTION                     │
└──────────────────────────────────────────────────────────────┘

What Happened
• Personal computers became affordable.
• Businesses started buying their own servers.
• Private server rooms became common.

Result
Companies managed their own infrastructure.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 6. 1990s – INTERNET REVOLUTION                              │
└──────────────────────────────────────────────────────────────┘

What Happened
• Websites became popular.
• Businesses needed servers running 24×7.

Problems
• Huge upfront investment (CapEx).
• Servers used only 10–20% of capacity.
• Scaling required buying hardware.
• Hardware failures caused downtime.
• High maintenance costs.

Key Takeaway
Businesses needed a better infrastructure model.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 7. Early 2000s – AMAZON'S OBSERVATION                       │
└──────────────────────────────────────────────────────────────┘

What Happened
• Amazon owned thousands of servers.
• Holiday seasons required maximum capacity.
• For most of the year, many servers remained idle.

Idea
Rent unused computing resources to other businesses.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 8. 2006 – BIRTH OF AWS                                      │
└──────────────────────────────────────────────────────────────┘

Amazon launched Amazon Web Services (AWS).

Businesses could now
• Rent virtual servers.
• Store data online.
• Scale within minutes.
• Pay only for what they used.

Result
Cloud computing became commercially available.

══════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│ 9. 2010s – CLOUD ADOPTION                                   │
└──────────────────────────────────────────────────────────────┘

Major Cloud Providers
• Microsoft Azure
• Google Cloud Platform (GCP)
• IBM Cloud
• Oracle Cloud

Result
Cloud became the preferred infrastructure for businesses.

☁ Why is it Called "Cloud"?
#  Network engineers used a cloud-shaped symbol in network diagrams to represent the Internet or an unknown network.
   eg : user - cloud - server

  Instead of drawing every router, cable, and switch, they simply used a cloud symbol.

Later, computing resources started being delivered over the Internet.

Hence the name

Cloud Computing

Cloud does NOT mean servers in the sky.

It simply means

Computing resources delivered over the Internet while hiding the underlying infrastructure.
