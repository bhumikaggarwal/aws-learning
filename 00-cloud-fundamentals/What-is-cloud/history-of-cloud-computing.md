# CLOUD - COMPUTING TIMELINE

1950s – Mainframe Era

What happened?

Huge computers occupied entire rooms.
Extremely expensive.
Used only by governments, banks, universities, and the military.

Problem

One computer served very few users.
Most computing power remained unused.
High hardware cost.

Result: Need a way to share computing resources.

1960s – Time Sharing

Innovation

Multiple users shared the same mainframe.
CPU rapidly switched between users.

Benefits

Better utilization of expensive computers.
Reduced computing cost.
First major step toward cloud computing.
1961 – John McCarthy's Vision

Idea

"Computation may someday be organized as a public utility."

Meaning

Computing should be available like electricity or water.
Users should consume computing resources whenever needed.
Pay only for what they use.

Importance

This became the conceptual foundation of cloud computing.
1970s – Virtualization

Innovation

One physical server could run multiple Virtual Machines (VMs).
Each VM behaved like an independent computer.

Benefits

Better hardware utilization.
Lower infrastructure cost.
Efficient resource sharing.

Importance

Virtualization is the backbone of modern cloud computing.
1980s – Personal Computer Revolution

What happened?

Personal computers became affordable.
Businesses started purchasing their own servers.
Private server rooms became common.

Result

Every company owned and managed its own infrastructure.
1990s – Internet Revolution

What happened?

Websites and online businesses became popular.
Companies needed servers running 24×7.

Problems

Huge upfront investment (CapEx).
Servers were mostly idle (only 10–20% utilized).
Scaling required buying new hardware.
Hardware failures caused downtime.
High maintenance costs.

Result: Businesses needed a better solution.

Early 2000s – Amazon's Observation

What happened?

Amazon owned thousands of servers.
During shopping seasons, servers were heavily used.
For most of the year, many servers remained idle.

Idea

Rent unused computing resources to other businesses instead of letting them sit idle.
2006 – Birth of AWS

What happened?

Amazon launched Amazon Web Services (AWS).

Businesses could now

Rent virtual servers.
Store data online.
Scale resources within minutes.
Pay only for the resources they used.

Result

Cloud computing became commercially available.
2010s – Cloud Adoption

What happened?

Microsoft launched Azure.
Google launched Google Cloud Platform (GCP).
IBM and Oracle expanded their cloud offerings.

Result

Cloud became the preferred way to deploy applications.
Today – Cloud Computing

Cloud powers services like:

Netflix
Amazon
Spotify
YouTube
Banking applications
AI platforms
OTT services
E-commerce

☁ Why is it Called "Cloud"?

#  Network engineers used a cloud-shaped symbol in network diagrams to represent the Internet or an unknown network.
   eg : user - cloud - server

  Instead of drawing every router, cable, and switch, they simply used a cloud symbol.

  Later, computing resources started being delivered over the Internet. Hence the name Cloud Computing

  Cloud does NOT mean servers in the sky.It simply means Computing resources delivered over the Internet while hiding the underlying infrastructure.
