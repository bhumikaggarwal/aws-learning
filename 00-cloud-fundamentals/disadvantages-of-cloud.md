# Disadvantages of Cloud Computing

Cloud computing offers scalability and cost benefits but also has certain limitations.

---

## 1. Internet Dependency
- Requires a stable internet connection.
- Poor connectivity impacts application availability and performance.

**Example:** Unable to access cloud services during an internet outage.

---

## 2. Downtime
- Cloud providers may experience service outages.
- Applications become temporarily unavailable until the issue is resolved.

**Example:** AWS region outage affecting hosted applications.

---

## 3. Security & Privacy Risks
- Data is stored on third-party infrastructure.
- Risk of unauthorized access or data breaches if security is compromised.

**Mitigation:** Encryption, IAM, MFA, Security Groups.

---

## 4. Vendor Lock-in
- Migrating applications and data between cloud providers can be difficult.
- Different providers use proprietary services and APIs.

**Example:** Migrating from AWS Lambda to Azure Functions requires code changes.

---

## 5. Cost Overruns
- Pay-as-you-go pricing can become expensive without proper monitoring.
- Idle or unused resources continue to generate charges.

**Example:** Running unused EC2 instances continuously.

---

## 6. Limited Control
- Physical infrastructure is managed by the cloud provider.
- Customers have limited control over hardware and underlying networking.

---

## 7. Compliance Challenges
- Some industries require data to be stored in specific regions.
- Organizations must comply with regulations such as GDPR, HIPAA, and PCI-DSS.

---

## 8. Performance & Latency
- Network delays can impact application response times.
- Greater distance between users and data centers increases latency.

---

## 9. Data Transfer Costs
- Uploading data is generally free.
- Downloading (egress) large amounts of data may incur significant charges.

---

## 10. Shared Responsibility
- Cloud Provider: Secures the cloud infrastructure.
- Customer: Secures applications, data, identities, and configurations.

---
